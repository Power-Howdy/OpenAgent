# Experiments

This directory contains scripts and configurations for reproducing experiments from the research paper.

## Structure

- `benchmark/` - Benchmark scripts for comparing providers
- `free-mode/` - Free mode routing evaluation
- `sandbox/` - Sandbox isolation tests

## Running Experiments

```bash
# Install dependencies
npm install

# Run benchmark
npm run experiment:benchmark

# Run free mode evaluation
npm run experiment:free-mode
```

Note: Experiment scripts will be added with the paper publication.
